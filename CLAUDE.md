## Superpowers

The Superpowers plugin (`superpowers@superpowers-marketplace`, https://github.com/obra/superpowers) is enabled for this project in `.claude/settings.json`.

- At the start of every task, follow the `superpowers:using-superpowers` skill and check which Superpowers skill applies before acting.
- Use `superpowers:brainstorming` before building something new, `superpowers:writing-plans` / `superpowers:executing-plans` for multi-step work, `superpowers:systematic-debugging` for bugs, `superpowers:test-driven-development` when writing code, and `superpowers:verification-before-completion` before saying work is done.
